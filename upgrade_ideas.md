# Upgrade ideas

Brainstormed upgrades for the hideout **workshop**. Nothing here is built yet —
all entries are **not implemented**.

- **Window.** Add a window to the hideout wall so the player can see out into the
  carnival (and, at Night, spot approaching guests). Not implemented.
- **Upgrade lamp.** An upgrade that brightens the hideout light so the player can
  see better inside. Not implemented.
- **Upgrade amount of better tickets.** An upgrade that raises the number of
  higher-value tickets (e.g. Fortune, and future rare types) spawned per night.
  Not implemented.
- **Quiet Soles.** Reduces the walk/sprint noise radii per level, making it
  easier to slip past Listeners. Not implemented.
- **Lockbox.** The first capture in a night no longer costs you carried tickets;
  only a second capture does. (Changes the current "lose everything" loss rule —
  confirm before building.) Not implemented.
- **Guest Tracker.** A HUD compass blip toward the nearest guest, with a
  cooldown, so you can read the room instead of walking blind. Not implemented.
- **Scavenger Bin.** Once per night the trashcan yields a free random ticket
  instead of only discarding them. Not implemented.
- **Lucky Charm.** Gives a small chance for a rolled Empty tile to reroll into a
  real icon (applied at roll time, so it only affects future tickets). Not
  implemented.
