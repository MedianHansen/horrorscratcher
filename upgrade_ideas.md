# Upgrade ideas

Brainstormed upgrades for the hideout **workshop**. Nothing here is built yet —
all entries are **not implemented**.

- **Window.** Add a window to the hideout wall so the player can see out into the
  carnival (and, at Night, spot approaching guests). Not implemented.
- **Upgrade lamp.** An upgrade that brightens the hideout light so the player can
  see better inside. Not implemented.
- **Upgrade amount of better tickets.** An upgrade that raises the number of
  higher-value tickets (e.g. Fortune, and future rare types) spawned per night.
  Not implemented.
